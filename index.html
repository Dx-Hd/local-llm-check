📖 怎么看这个表

  • ✓ 可运行 配置满足需求，建议直接部署
  • ⚠ 可用（受限） 显存不够走 CPU 混合推理，或仅核显/低配，速度偏慢但可用
  • ✗ 内存不足 连内存都不够，需换量化或加内存
  • 需内存 = 模型文件 + 约 4GB 系统开销；需显存 = 模型文件 + 约 1.5GB KV缓存开销
  • MoE 模型（如 Qwen3-30B-A3B）虽然文件大，但每次只激活少量参数，速度接近小模型，是低配机器跑大模型的捷径
  • 量化说明：Q4_K_M 精度损失小、体积小，日常使用首选；Q8_0 几乎无损但体积翻倍；FP16 是原始权重，一般仅高端显卡使用
  • 估算误差来源：内存类型/通道数、CPU 核心数、散热降频、Ollama/llama.cpp 版本差异等

本站所有检测结果与速度估算仅供参考，均为浏览器端本地计算，不上传任何数据。数据与公式见 js/models.js、js/estimate.js。
